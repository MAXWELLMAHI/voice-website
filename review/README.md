# Mumbai visual mock-up

The images are actual browser captures of the implemented landscape scene at 1440×900, plus a narrow 390×844 capture. The storyboard combines the three desktop frames. Run `render_storyboard.py` with Pillow to rebuild it from the captures.

Reproducible still views:

- `/mumbai-alley.html?still=sleep`
- `/mumbai-alley.html?still=respect`
- `/mumbai-alley.html?still=deeper`

Open `/mumbai-alley.html` for the scrolling version, or find the section in the full website. Still views use the same geometry, camera travel, text materials and lighting as the scroll journey.
